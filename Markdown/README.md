# Markdown Dokumentation

## 3 fordele ved at bruge Markdown

* Enkelt og hurtigt at lære: Markdown bruger almindelige tegn (som # for overskrifter og ** for fed skrift) til at formatere tekst. Det er intuitivt, nemt at læse og kræver ingen forhåndskendskab til HTML.

* Platformuafhængig og fremtidssikret (Portabilitet): Da Markdown-filer er rene tekstfiler (.md), kan de åbnes og redigeres i ethvert tekstprogram, hvilket betyder, at dine dokumenter ikke er låst til ét specifikt program og kan læses om 50 år.

* Effektivt til konvertering og teamsamarbejde: Markdown kan nemt konverteres til HTML, PDF og andre formater. Det fungerer perfekt med versionsstyringsværktøjer som Git, hvilket gør det ideelt til teknisk dokumentation og teams, der samarbejder.

# Kodeeksempler

## Javascript
```Javascript 
// Vi definerer et array med forskellige frugter
const frugter = ["Æble", "Banan", "Appelsin", "Mango"];

// Vi bruger et for-loop til at gå igennem arrayet
// 1. Vi starter ved index 0 (let i = 0)
// 2. Vi kører så længe i er mindre end arrayets længde (i < frugter.length)
// 3. Vi lægger 1 til i for hver omgang (i++)
for (let i = 0; i < frugter.length; i++) {
  console.log("Frugt på plads " + i + ": " + frugter[i]);
}
```
